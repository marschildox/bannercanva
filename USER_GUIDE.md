# 🎨 Banner Generator - User Guide

## Welcome!

Banner Generator is a professional tool that helps you create multiple banner formats from a single master design. Perfect for creating complete ad campaigns across Google Ads, social media platforms, and more.

## 🚀 Quick Start

### Step 1: Design Your Master Banner

1. The first **1:1 Square** banner (top-left) is your **Super Master**
2. Click on it to open the editor sidebar
3. Design your banner using the three tabs:
   - **Content**: Images, text, CTAs
   - **Style**: Colors, sizes, effects
   - **Layout**: Positioning

### Step 2: Add More Formats

1. Click the **"Add Horizontal"** or **"Add Vertical"** buttons
2. New columns will appear with format-specific banners
3. All new banners automatically inherit your master design!

### Step 3: Customize Individual Banners (Optional)

- Click any non-master banner to customize it individually
- Changes to child banners only affect that specific banner
- Changes to master banners affect all children in that column

### Step 4: Export Your Banners

Choose from three export options:

1. **Export Selected**: Export just the banner you've selected (PNG)
2. **Export Column**: Export all banners in a specific column (ZIP)
3. **Export All**: Export your complete banner set (ZIP)

## 🎨 Master-Child System

### Super Master (1:1 Square)

The **first square banner** has special power:

```
┌──────────┐
│  Super   │ ──► Changes affect ALL banners
│  Master  │     in ALL columns
│    👑    │
└──────────┘
```

**When you edit the Super Master:**
- ✅ All horizontal banners update
- ✅ All vertical banners update
- ✅ All child banners update
- ⚡ Total control over your entire banner set

### Column Masters

Each column has a master banner:

```
┌──────────┐
│ Column   │ ──► Changes affect children
│  Master  │     in THIS column only
│    👑    │
├──────────┤
│  Child   │ ◄── Receives updates
├──────────┤
│  Child   │ ◄── Receives updates
└──────────┘
```

**When you edit a Column Master:**
- ✅ All children in that column update
- ❌ Other columns are NOT affected

### Child Banners

Regular banners without master status:

```
┌──────────┐
│  Child   │ ──► Changes affect ONLY itself
│  Banner  │
└──────────┘
```

**When you edit a Child Banner:**
- ✅ Only that specific banner changes
- ❌ No other banners are affected
- 🎯 Perfect for format-specific tweaks

## 📥 Export System

### Single Banner Export

1. Click on the banner you want to export
2. Click **"Export Selected"** in the toolbar
3. PNG file downloads immediately
4. Filename: `BannerName_1080x1080.png`

### Column Export

1. Click **"Export Column"** dropdown
2. Select which column to export
3. ZIP file downloads with all banners
4. Filename: `Square_banners.zip` (or Horizontal/Vertical)

### Complete Set Export

1. Click **"Export All (X)"** button
2. All banners export to a single ZIP
3. Wait for progress indicator
4. Filename: `banner_set_complete_set.zip`

### Export Quality

- **Format**: PNG (lossless)
- **Scale**: 2x (high resolution)
- **Quality**: 100% (maximum)

## 💡 Pro Tips

### 1. Design Mobile-First

Start with vertical formats (Instagram Stories) to ensure text is readable on small screens.

### 2. Use the Super Master Wisely

Make major changes (colors, images, branding) on the Super Master to update everything at once.

### 3. Test Different CTAs

Create multiple banner variations by:
1. Export your base set
2. Change CTA text on Super Master
3. Export again
4. Compare performance

### 4. Organize Your Workflow

Recommended order:
1. ✅ Design Super Master (1:1)
2. ✅ Add horizontal column → Review → Adjust if needed
3. ✅ Add vertical column → Review → Adjust if needed
4. ✅ Export complete set

### 5. Zoom for Precision

- Use **25%** zoom to see all banners at once
- Use **100%** zoom to pixel-perfect your design
- Hotkey: Click Maximize icon for instant 100%

### 6. Format-Specific Customization

Some banners need tweaks:
- Skyscrapers (160x600): Smaller font sizes
- Leaderboards (728x90): Horizontal-optimized text
- Stories (1080x1920): Vertical-optimized layouts

Edit these individually after setting up the master!

## ❓ FAQ

**Q: Can I undo changes?**
A: Currently no undo. Make small changes and export frequently!

**Q: What image formats are supported?**
A: JPG, PNG, and any URL-accessible image.

**Q: Can I save my project?**
A: Not yet. Export your banners to preserve your work.

**Q: How many banners can I export at once?**
A: Unlimited! The system processes them sequentially.

**Q: Why is export slow?**
A: High-quality rendering takes time. Larger banners and more elements = longer export.

**Q: Can I change banner dimensions?**
A: Dimensions are predefined for common ad formats. Custom sizes coming soon!
